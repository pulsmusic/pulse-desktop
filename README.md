# Пульс для Windows — альфа 0.14.15

Программа для компьютера в дизайне «Пульса»: боковое стеклянное меню, свет сверху в цвете профиля,
плеер внизу окна, «Мой пульс» со стопкой карточек, полный плеер. Музыка — из Яндекс Музыки
(без отдельного сервера: запросы к Яндексу делает сама программа).

## Обновления

Профиль → «Обновления» → «Проверить обновления». Программа сама проверяет их при каждом запуске и показывает
подсказку и точку на аватаре, если вышла новая версия. Обновление (~0,4 МБ) ставится за пару секунд без
переустановки: скачивается, сверяется по SHA-256, текущие файлы сохраняются в `%APPDATA%\Pulse\update-backup`,
программа перезапускается. Вход, лайки и настройки не трогаются.

Откуда берутся: последний релиз репозитория **github.com/pulsmusic/pulse-desktop** — файлы `latest.json`
и `pulse-app-<версия>.zip`. Как выпустить новую версию:
1. Поднять `version` в package.json, собрать интерфейс (`npm run build:ui`).
2. `python3 tools/make-update.py "Что нового 1" "Что нового 2"` — появится папка `release-update`.
3. На GitHub: Releases → Draft a new release → тег `v<версия>` → прикрепить `latest.json` и `pulse-app-<версия>.zip`
   (и установщик, если менялся) → Publish. Или одной командой: `bash tools/publish-update.sh "Что нового"` (нужен gh).

## Установщик (самый простой способ)

Запустите **Pulse-Desktop-Alpha-Setup.exe** → «Установить». Всё нужное уже внутри, интернет не нужен.
На рабочем столе появится ярлык **«Пульс Десктоп Альфа»**. Удалить — через «Параметры → Приложения».
Исходники установщика — в папке `installer/`.

## Как получить .exe на Windows — ничего ставить не нужно

1. Распакуйте архив в любую папку (например, на Рабочий стол).
2. Дважды щёлкните **build-win.bat**.
3. Подождите 3–7 минут при первой сборке, дальше быстрее. Откроется папка `release` с файлом **Pulse-0.9.4.exe**.

Устанавливать Node.js не надо: сборщик сам скачает переносной Node.js в скрытую папку `.tools` рядом с проектом
(в систему ничего не ставится, перезагрузка не нужна). Готовому **Pulse.exe** Node.js не нужен вовсе —
Electron несёт внутри всё своё. Exe можно переносить на любой компьютер с Windows 10/11 и запускать двойным щелчком.

Windows может показать «Windows защитила ваш компьютер» — это потому что программа не подписана
сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

Запустить без сборки exe (для проверки): двойной щелчок по **run-win.bat** — тоже без установки Node.js.

## Как получить .exe на Mac

Откройте Терминал, напечатайте `bash ` (с пробелом), перетащите в окно файл **build-win.sh** и нажмите Enter.

## Посмотреть сразу на Mac

Так же: `bash ` + перетащить **run-mac.sh** + Enter.

## Вход в Яндекс Музыку

В программе: левый нижний угол → Настройки → «Получить токен» → войти в браузере → скопировать весь адрес
из строки браузера → вставить → «Сохранить». Без входа играют 30-секундные фрагменты, с Плюсом — треки целиком.
Токен хранится только на этом компьютере.

## Клавиши

Пробел — пауза · ← → — перемотка на 5 с · Ctrl ↑ ↓ — громкость · Ctrl K — поиск · Esc — закрыть плеер.
В «Моём пульсе»: → — следующий трек, ← — прошлый; лайк и «не нравится» — кнопками внизу. Медиаклавиши клавиатуры и плашка Windows с обложкой тоже работают.

## Что внутри

- `main.js` — окно (своя шапка, системные кнопки Windows), мост к Яндекс Музыке.
- `yandex.js` — клиент Яндекс Музыки (поиск, чарт, артисты, альбомы, «Моя волна», ссылки на звук).
- `src/` — интерфейс (React). Уже собран в `dist/`; пересобрать после правок: `npm run build:ui`.

## 0.14.15 — правило: островок не меняет высоту

- Правило дизайна: островок в шапке всегда ровно 52 в высоту со скруглением 26 — при любом содержимом, фокусе, нажатии и анимации. Высота закреплена (height/min/max), масштаб и сдвиги запрещены, анимируется только ширина.

## 0.14.14 — островок не съезжает после нажатия

- При фокусе строки поиска браузер прокручивал островок (overflow: hidden) на 5 px вниз, и содержимое уезжало вверх. Теперь фокус с preventScroll, у островка и слоёв overflow: clip, а случайная прокрутка сразу сбрасывается.

## 0.14.13 — островок без «…» во время анимации

- Содержимое каждого слоя островка сразу размечается на конечную ширину и больше не переразмечается, пока островок тянется: край просто открывает готовую строку, «…» не мелькают. Уходящий слой держит свою прежнюю ширину.

## 0.14.12 — строка поиска-островок

- Строка поиска в шапке стала «островком»: высота всегда 52 (скругление 26), меняется только длина — плавно, под содержимое (длину меряем по настоящему слою до кадра). Всё внутри — круги и капсулы 36 с отступом 8, скругление 18 = 26 − 8.
- Островок на пару секунд показывает: смену трека (обложка, название, артист, эквалайзер; по краю пробегает градиент), лайк, громкость, ход разметки ИИ и «Текст размечен», выход обновления с кнопкой «Обновить» и ход установки (вместо прежнего баннера).
- Поиск важнее всего: клик по островку, Ctrl K или набранный текст сразу возвращают строку поиска.

## 0.14.11 — ровные кольца со скруглёнными концами, настоящий градиент тем

- Кольцо у кружков артистов — окружность SVG толщиной 4 со скруглёнными концами, фото с отступом 4 со всех сторон (раньше общее правило «.art span { max-width }» сжимало кольцо в овал). Подпись «N из M» не больше общего числа.
- Градиентные темы: у каждой — три различимых цвета (ray); лучи сверху, подсветка пункта меню, переключатели, полосы прогресса, эквалайзер и кольца — настоящим градиентом, переход в OKLCH.

## 0.14.10 — ровные кольца у артистов

- Кольцо «сколько прослушано» — ровной толщины (фото точно по центру: box-sizing и центрирование), без тёмной рамки между фото и кольцом.

## 0.14.9 — плеер помнит, что играло

- Трек, место в нём и очередь (с источником) сохраняются (pulse.session): при смене трека, каждые 5 с во время игры, на паузе и при закрытии окна — значит, и перед перезапуском для обновления. При запуске трек встаёт на место на паузе, с того же момента; «играть» продолжает.

## 0.14.8 — кольца «сколько прослушано» и страница чарта

- Кружки артистов на главной: кольцо — доля прослушанных треков артиста (от всех его треков на Яндексе), под именем — «N из M». Прослушанным считается трек, игравший 30 с (при первом запуске — любимые и недавние); хранится у себя (pulse.heard).
- «Весь чарт» (вместо «Слушать все») открывает отдельную страницу чарта — все 100 треков, «Слушать» и «Перемешать».

## 0.14.7 — ссылки на артистов без подчёркивания

- При наведении имя артиста (и альбома) больше не подчёркивается — плавно становится ярким (в тёмной теме — белым).

## 0.14.6 — ИИ-разметка v3 и «Есть ошибка?»

- Разметка v3 (aligner/src/aligner.js; код приходит с обновлением как ai-aligner.js, модель — прежняя): куски до 12 с по границам строк, основной текст и эдлибы — отдельными проходами, полоса голоса (150 Гц – 4,5 кГц) перед разметкой, начало каждого слова доводится до вступления голоса (±0,15 с), неправдоподобная разметка строки отбрасывается (остаётся подсветка по слогам).
- Новая база: отпечаток текста с «v3», локальный кэш — cache-v3.json (старый удаляется); сервер (online-server, нужно обновить) удаляет разметки до v3 и принимает пересчёт по кнопке (r).
- «Есть ошибка?» в живом тексте: в основном тексте / в эдлибах / везде — ИИ слушает трек тремя способами и берёт вариант, заметно отличающийся от прежнего.

## 0.14.5 — плавный живой текст

- Каждая строка — отдельный компонент (React.memo): при смене строки перерисовываются только 5–6 строк, у которых изменился вид; перерисовка — через startTransition, не в ущерб кадру.
- Ширина слов измеряется заранее, разом для всех строк (и при изменении окна), а не посреди анимации смены строки — без принудительного пересчёта раскладки.
- Ушедшая строка уходит в размытие одним движением (цвет, свечение и подсветка слов — одна кривая, 0,7 с) и дальше не меняется.
- Текущая, следующая и только что ушедшая строки — на своих слоях видеокарты: масштаб без повторной отрисовки текста.

## 0.14.4 — скругление карточек и фото артистов

- Карточки «Лучшее артистов» и «Собрано для вас» держат скругление целиком (маска), углы не становятся квадратными после наведения.
- Фото артистов: не больше 4 запросов разом, до 3 попыток, запасной источник (страница артиста), повтор через 15 и 45 с, «фото нет» перепроверяется через сутки; картинка, которая не загрузилась, перезапрашивается.

## 0.14.3 — главная: одинаковые карточки

- Карточки «Новых релизов», «Ваших плейлистов» и «Подборок» — того же размера, что и остальные (210).

## 0.13.6 — обложка на паузе

- На паузе обложка сжимается к своему центру и не смещается.

## 0.13.5 — живые иконки

- У кнопок плеера и действий — короткие анимации (icons.jsx → IA): играть↔пауза, повтор/повтор трека (оборот, огонёк, «1»), лайк с искрами, трещина дизлайка, волны громкости и др.

## 0.13.4 — эдлибы сами по себе

- Эдлибы снова светятся в свой момент (по своему времени), но независимо от основного текста: не обрывают основные слова и не ждут их.
- Без времени слов — снова по порядку текста.

## 0.13.3 — индикатор ИИ

- В живом тексте значок: «ИИ размечает текст · N%», «ИИ загружает модель», «в очереди», «включится на зарядке», «Время слов — ИИ».
- В режиме разработчика — состояние ИИ (модель, очередь, сколько треков размечено, может ли считать).

## 0.13.2 — эдлибы параллельно

- Эдлибы (в скобках) подсвечиваются параллельно основному тексту — их волна идёт через всю строку.

## 0.13.1 — живой текст: паузы исполнителя

- Слово подсвечивается не дольше, чем его можно спеть (~0,3 с на слог, до 1,8 с): замолчал — подсветка ждёт следующего слова.
- Строка заканчивается, когда спето последнее слово, а не тянется до следующей; в проигрыше она приглушается.

## 0.13.0 — ИИ-разметка живого текста

- Для песен, у которых есть только время строк, время каждого слова определяет ИИ (Whisper base, MIT) — принудительным
  выравниванием по известному тексту. Всё автоматически: сначала общая база на сервере (online-server, /align),
  иначе — тихий расчёт в фоне (от сети, не слабый ПК, низкий приоритет), результат уходит в общую базу.
- Пакет ИИ собирается и проверяется в CI (aligner/, .github/workflows/ai-pack.yml) и скачивается программой один раз.
- На сервер уходят только номер трека, отпечаток текста и время слов.

## 0.12.8 — исполнители по центру, меню закрываются щелчком в любом месте

- Список исполнителей трека — окно по центру приложения, помещается любое количество.
- Все меню закрываются щелчком в любом свободном месте (в том числе по полосе заголовка), по Esc и при уходе из окна.

## 0.12.7 — живой текст: эдлибы и анимации

- Строка под курсором больше не остаётся светлой — подсветка при наведении только при прокрутке текста.
- Текст при закрытии плавно уезжает вместе с обложкой, при смене трека — проявляется без повторного «въезда».
- Время слов не путается при смене трека.

## 0.12.6 — живой текст: мягкие края размытия

- Размытие строк больше не обрезается по краям.
- При прокрутке текста вручную размытие снимается.
- Следующие строки тише текущей.

## 0.12.5 — полноэкранный режим и производительность

- Полноэкранный режим: F11 или кнопка рядом с профилем и в большом плеере; Esc — выход.
- Живой текст встаёт напротив центра обложки; ушедшие строки мягко размыты.
- Живой фон без полноэкранных фильтров, экран под большим плеером не рисуется, анимации замирают без фокуса.

## 0.12.4 — карточки «Моего пульса» и аватары исполнителей

- Градиент под названием в цвет обложки, плавно переходящий в неё.
- Вместо имени исполнителя — кружки-аватары; по нажатию выбирается исполнитель.
- Ровная подложка под аватарами, полупрозрачные обводки вместо чёрных.

## 0.12.3 — живой текст: плавная смена строк и синхронизация
- Размытие строк — мягкой тенью текста, а не фильтром: без «коробок» по краям и без подтормаживаний.
- Смена строки без вспышек: свет ушедшей строки плавно гаснет вместе с переходом в размытие; у всех строк одинаковая вёрстка — ничего не прыгает.
- Всё помещается: размер шрифта зависит от окна, длинные строки переносятся, текущая строка увеличивается меньше.
- Синхронизация: новая оценка по слогам (строку поют почти до следующей; на проигрыше — с обычной скоростью), подсветка по слогам без опережения; кнопки «− / +» сдвигают текст раньше/позже на 0,2 с — запоминается для трека.
- В мини-плеере — кнопка «Текст» (открывает плеер сразу с текстом); значки справа одного размера и ровно в ряд.

## 0.12.2 — живой текст: мягче и плавнее
- Свечение спетого — заметно слабее и без «коробочек»: слой подсветки больше слова, свечение не обрезается.
- Эдлибы в скобках — отдельной маленькой строкой под основной (без скобок), подсвечиваются в свой момент.
- Край волны догоняет время плавно (без рывков на границах слов), внутри слова — мягкий разгон и торможение; прокрутка и смена строк — мягкая «пружина», строки при открытии появляются по очереди.

## 0.12.1 — живой текст на фоне
- Кнопка «Текст» в большом плеере: обложка и управление плавно уезжают влево, справа — текст прямо на живом фоне (без блока).
- Текущая строка заливается светом по буквам мягкой волной (по словам — перенос строк не мешает), спетое светится неоном в цвете профиля; прошлые строки размыты (сильнее выше), следующие — слегка, тем сильнее, чем дальше. Щелчок по строке — перемотка, колесо — листать.
- Время слов: если источник дал текст по словам (расширенный LRC: <мм:сс.хх> перед каждым словом — бывает в LRCLIB), подсветка идёт точно по нему, и такой текст важнее строчного; иначе — расчёт по слогам (гласным) от времени строки.

## 0.12.0 — плейлисты, живой фон, профиль по разделам
- Свои плейлисты (как на телефоне): «+» в меню слева и «Новый плейлист» в «Моей музыке», «…» у трека → «Добавить в плейлист», меню в большом плеере; страница плейлиста: переименовать (двойной щелчок по названию), своя обложка или мозаика из треков, удалить, убрать трек.
- «Мой пульс» бесконечный: при конце очереди не начинается заново (повтор к нему не относится), уже звучавшие в этом запуске треки не повторяются, несколько попыток подгрузки.
- Живой фон большого плеера: обложка, размытая заранее (64×64, три прохода) + мягкое размытие, два слоя медленно плывут; в такт басу фон «дышит» — если сервер Яндекса разрешает читать звук (проверка CORS в главном процессе; иначе звук не трогаем).
