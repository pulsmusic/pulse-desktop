# Установщик «Пульс Десктоп Альфа»

Собирается автоматически (.github/workflows/release.yml) для каждой новой версии из `updates/<версия>/`:
Electron 33.2.1 (x64) скачивается с GitHub и сверяется по SHA-256, файлы программы берутся из `pulse-app-<версия>.zip`.
Готовый `Pulse-Desktop-Alpha-Setup.exe` прикрепляется к релизу.

Что делает: проверяет Windows (10/11) и место на диске, распаковывает программу в `%LOCALAPPDATA%\Programs\Pulse`,
проверяет все файлы (недостающие дописывает), пробно запускает «Пульс» (`--pulse-selftest`; не вышло — без видеокарты,
тогда включает безопасный режим), создаёт ярлыки и запись в «Установке и удалении программ».
